# 风格预设库（21 种，点名即用）

用户说出风格名（或别名），直接套用对应预设，不要自行发挥。
每个预设包含：配色 token、字体搭配、形状语言、标志性元素、动效、避坑。
风格决定「皮肤」，页型决定「骨架」——任何预设都可以套在六种页型上。

## 使用规则

1. 用户点名风格 → 只用该预设 token，不得混入其他预设的颜色或装饰。
2. 未点名 → 按 `visual-system.md` 三选一默认基调。
3. 一次汇报只允许一个预设；用户点名多个时，提醒选一个。
4. 黑名单（紫蓝渐变、emoji 图标等）仅对「未点名风格」生效；点名预设后按预设规则执行，但「编造数据」「改写原文」红线永远生效。
5. 每个预设的 CSS token 直接替换 `starter.html` 的 `:root` 变量，装饰元素按预设追加。

## 组 A：布局不变 · 左右各价（编号 1-9）

骨架：左侧竖排窄栏（导航/价格/列表），右侧大标题区 + 主视觉。

### 01 赛博朋克 Cyberpunk
- 别名：霓虹、故障风
- token：`--bg:#0D0221; --ink:#F8F2E9; --muted:#8F9AAF; --accent:#FF2A6D; --accent2:#05D9E8;`
- 字体：标题无衬线加粗 + 局部描边字（`-webkit-text-stroke`），数字等宽
- 形状：直角切角边框（`clip-path: polygon` 切一角）、1px 霓虹描边 + 同色外发光
- 标志性元素：扫描线（repeating-linear-gradient 半透明）、故障错位标题（两层文字错位 3px，一红一青）、顶部细小英文坐标文字
- 动效：偶发闪烁（glitch 一次 200ms，勿循环）
- 避坑：全页发光、超过 2 种霓虹色、紫底蓝字（对比度不够）

### 02 复古终端 Retro Terminal
- 别名：绿屏、老电脑、黑客终端
- token：`--bg:#0A0F0A; --ink:#33FF66; --muted:#1E8C3E; --accent:#B4FF57;`
- 字体：全部等宽（--font-mono），标题可全角空格拉开
- 形状：1px 绿色实线边框 + 双线外框（border + outline 间隔 4px）
- 标志性元素：`>` 提示符、下划线光标闪烁、ASCII/字符画图形、页脚 fake 状态栏（如 `[OK] loaded`）
- 动效：光标 blink（1s step），打字机入场（可选）
- 避坑：圆角、阴影、彩色——一律不用；不要做成「黑客攻击」剧情页

### 03 拟物 Skeuomorphism
- 别名：木纹、皮革、仿真
- token：`--bg:#4A342A（木纹底）→用 repeating-linear-gradient 木纹; --ink:#F3E9D8; --accent:#C8A24B（黄铜）;`
- 字体：标题衬线（--font-serif），正文无衬线
- 形状：大圆角 12px + 内阴影（inset 高光上、暗影下）+ 落影，面板像实物
- 标志性元素：木纹/皮革纹理背景（CSS 渐变模拟，禁外图）、黄铜色小铭牌、缝线虚线边框
- 动效：按下按压效果（active 时 inset 阴影反转）
- 避坑：纹理用外链图片；整个页面做成游戏 UI

### 04 玻璃拟态 Glassmorphism
- 别名：磨砂玻璃、毛玻璃
- token：`--bg: 彩色柔和渐变底（青绿系 #3E8E7E→#67B8A5 等）; --panel: rgba(255,255,255,.18); --ink:#FFFFFF; --accent:#FFD98E;`
- 字体：无衬线，白色为主
- 形状：大圆角 20px + `backdrop-filter: blur(16px)` + 1px 半透明白描边（rgba(255,255,255,.35)）
- 标志性元素：背景放大版彩色模糊光斑（2-3 个，position:absolute + blur(80px)）、玻璃卡片浮在其上
- 动效：光斑缓慢漂移（60s 线性循环）
- 避坑：文字直接压在光斑上（必须落在玻璃面板内）；底图太花导致文字对比度不足

### 05 粗野主义 Brutalism
- 别名：粗暴风、原始风
- token：`--bg:#F2F0E9（米白）; --ink:#111111; --accent:#FF4400; --accent2:#FFD400;`
- 字体：超大黑体（900 字重），可以字压字
- 形状：直角、3-4px 纯黑粗边框、硬阴影 `8px 8px 0 #111`
- 标志性元素：边框密集堆叠、贴纸式旋转小块（rotate 3-6deg）、跑马灯文字条、明显杂乱的角落小字
- 动效：hover 时硬阴影位移（无过渡，瞬移）
- 避坑：任何圆角、渐变、阴影模糊——一律禁止；不是「乱」而是「糙得有秩序」

### 06 波普艺术 Pop Art
- 别名：漫画风、波普
- token：`--bg:#FFE135（黄）; --ink:#111111; --accent:#E4002B（红）; --accent2:#0072CE（蓝）; --panel:#FF9EBB（粉）`
- 字体：标题特粗无衬线 + 白字黑描边（text-shadow 四向 2px 模拟）
- 形状：粗黑描边（3px）+ 硬阴影；爆炸贴（星形，用 clip-path 或 CSS polygon）
- 标志性元素：Ben-Day 网点（radial-gradient 圆点平铺）、爆炸贴写「NEW/低价」、对话气泡框
- 动效：爆炸贴轻微抖动（2 帧 step）
- 避坑：网点太密（4px 间距以上）；超过红黄蓝粉四色

### 07 孟菲斯 Memphis
- 别名：孟菲斯几何
- token：`--bg:#FFF8E7（奶油）; --ink:#221C35; --accent:#FF6B9D（粉）; --accent2:#2EC4B6（青绿）; --accent3:#FFC53D（黄）`
- 字体：无衬线粗体，局部可描边空心字
- 形状：色块直角 + 黑色细描边；元素随性旋转
- 标志性元素：波浪线（SVG path）、撒落的几何碎片（三角/圆/网格点阵）、锯齿线分隔
- 动效：几何碎片漂浮（8s ease-in-out 循环，幅度 6px）
- 避坑：排太满（留白 30%+）；碎片盖住文字

### 08 杂志排版 Editorial
- 别名：杂志风、报刊风
- token：`--bg:#FAF7F0; --ink:#1A1A1A; --accent:#0E4F45（墨绿）或 #8C1C13（砖红）; --line:rgba(26,26,26,.25)`
- 字体：标题超大衬线 + 内文无衬线；可用竖排标题（writing-mode: vertical-rl）
- 形状：直角；1px 细线分栏（border-left）、双细线页眉页脚
- 标志性元素：巨大字号标题压图、期号/栏目眉（小字 + 细线）、目录式编号（01 02 03）、首字下沉
- 动效：几乎无（仅入场 fade）
- 避坑：卡片阴影；栏宽不齐（严格等分或明确主次 2:1）

### 09 瑞士风格 Swiss Style
- 别名：国际主义、Helvetica 风
- token：`--bg:#F4F4F2; --ink:#111111; --accent:#E30613（正红）;`
- 字体：全无衬线（--font-sans），字重只有 400/700
- 形状：直角无装饰；严格 12 列网格，全部左对齐
- 标志性元素：大面积留白 + 一个正圆色块、字号对比（96/56/28 三档即可）、细网格参考线（可选，8% 透明度）
- 动效：无
- 避坑：居中对齐、斜体、衬线、装饰图案——全部禁止

## 组 B：布局不变 · 底下三张卡（编号 10-19）

骨架：上部 2/3 大标题区 + 主视觉，底部横排三张等宽产品卡。

### 10 黏土拟态 Claymorphism
- 别名：软糖风、捏捏乐
- token：`--bg:#FDEFE3（奶油粉）; --ink:#5C4B51; --accent:#FF8A5C（珊瑚橙）; --panel:#E8F4EA / #E3E8FF / #FFE9D6（马卡龙面板色）`
- 字体：无衬线圆体感（PingFang 即可），字重 600
- 形状：超大圆角 24-32px + 双层阴影（外落影柔和 + 内 inset 白色高光），像充气软块
- 标志性元素：胖乎乎的 3D 感图标（用 CSS 渐变+阴影模拟，禁外图）、圆点散落装饰
- 动效：按压回弹（cubic-bezier(.3,1.6,.5,1)）
- 避坑：深色底（黏土只在浅暖底上成立）；边框描线

### 11 新拟态 Neumorphism
- 别名：软 UI、凹凸拟物
- token：`--bg:#E8EBF0（单色浅灰底）; --ink:#4A5568; --accent:#C4956A（暖棕点缀，唯一彩色）;`
- 字体：无衬线
- 形状：圆角 16px；凸起 = 双阴影 `8px 8px 16px #c9cdd4, -8px -8px 16px #ffffff`；凹陷 = 反向
- 标志性元素：同色凸起面板、圆形凸起开关、按压变凹（active 反转阴影）
- 动效：按压凹凸切换（150ms）
- 避坑：引入第二种面板色（新拟态只有「同色」）；深色底 + 彩色面板混搭

### 12 千禧 Y2K
- 别名：Y2K、千禧风
- token：`--bg: 镭射渐变 #C9E4FF→#FFD6F2→#D9FFF0; --ink:#4A3B8C; --accent:#7CE0FF; --chrome: 金属银渐变 #E8E8F0→#B8BCD0`
- 字体：无衬线粗体 + 斜体点缀；数字可用 --font-mono
- 形状：胶囊按钮、气泡窗（老 Windows 窗口：银灰标题栏 + ✕ 按钮）、椭圆大圆角
- 标志性元素：镭射/虹彩渐变、果冻质感高光（椭圆白色高光块）、老式窗口组件（标题栏+边框+按钮）、星星闪光点缀
- 动效：虹彩缓慢流动（背景 position 20s 循环）
- 避坑：做成赛博朋克（Y2K 是亮色未来感，不是暗黑霓虹）

### 13 像素风 Pixel Art
- 别名：8-bit、复古游戏
- token：`--bg:#F5EAD7（米黄）; --ink:#2B2B2B; --accent:#E85D3D; --accent2:#3E7C4F; --window:#87CEEB（天空蓝面板）`
- 字体：等宽或像素感字体；字号取整数倍（14/28/56）
- 形状：全部直角；`image-rendering: pixelated`；边框用 box-shadow 拼像素阶梯（4px 步进）
- 标志性元素：像素图形（CSS box-shadow 多影拼图，禁外链图片）、游戏对话框（黑边白底 + 尾巴）、血条/分数栏（HP ××××）、格子地板背景
- 动效：step 硬切闪烁（steps(2)），禁止平滑缓动
- 避坑：平滑圆角与渐变；图标用非像素图形

### 14 新粗野主义 Neubrutalism
- 别名：新野兽派、亮色硬阴影
- token：`--bg:#F5F1E8; --ink:#111111; --accent:#FF6B6B（珊瑚红）; --accent2:#4D96FF（亮蓝）; --accent3:#FFD93D（柠黄）; --panel:#6BCB77（草绿）`
- 字体：无衬线特粗
- 形状：直角或小圆角 4px + 3px 黑描边 + 硬阴影 `6px 6px 0 #111`
- 标志性元素：高饱和色块卡片、色块间强对比拼贴、贴纸式按钮（描边+阴影）
- 动效：hover 位移阴影（150ms 线性）
- 避坑：与 05 粗野主义混淆——本风格色彩明亮愉悦，Brutalism 黑白红且更躁

### 15 包豪斯 Bauhaus
- 别名：构成主义、三原色几何
- token：`--bg:#F0EDE6; --ink:#111111; --accent:#D93025（红）; --accent2:#1A73E8（蓝）; --accent3:#F9AB00（黄）`
- 字体：无衬线，标题全大写间距可加宽
- 形状：直角面板；几何图形只用圆、方、三角
- 标志性元素：大色块几何构成（红圆/黄方/蓝三角重叠组合）、粗黑线条、色块上的白色数字
- 动效：几何块一次入场到位，无循环
- 避坑：超过红黄蓝黑四种颜色；曲线和自由形状

### 16 蒸汽波 Vaporwave
- 别名：蒸汽波、怀旧霓虹
- token：`--bg: 粉紫渐变 #2D1B69→#FF71CE→#01CDCD; --ink:#FFFFFF; --accent:#FF71CE（粉）; --accent2:#01CDCD（青）; --accent3:#FFFB96（柠黄）`
- 字体：标题可用衬线或全角字符拉开（「青 萍 咖 啡」）
- 形状：直角网格地面（透视网格，CSS transform + repeating-linear-gradient）、窗口组件描白边
- 标志性元素：落日条纹球（半圆+横条遮罩）、希腊/日文小字拼贴、雕塑感圆形主视觉、老窗口框
- 动效：网格向后滚动（20s 线性循环）
- 避坑： readability——文字必须落在深色或实色面板上，不能直接压渐变

### 17 极光渐变 Aurora Gradient
- 别名：柔光、弥散光
- token：`--bg:#0E1225（深夜底）; --ink:#F2F4FF; --muted:#A9B2D9; --accent:#7FF0D3（薄荷青）; --accent2:#C99CFF（淡紫）; --accent3:#FF9EC3（樱粉）`
- 字体：无衬线细体（300/400）+ 数字等宽
- 形状：大圆角 24px 半透明面板 rgba(255,255,255,.08) + 1px rgba(255,255,255,.18) 描边
- 标志性元素：3-4 个超大模糊光斑（blur 100px+，青/紫/粉），互相叠出极光感；细颗粒噪点（可选 SVG feTurbulence）
- 动效：光斑极慢漂移（40s 循环）
- 避坑：光斑盖文字（文字必须落面板）；饱和度拉满（保持低饱和柔光）

### 18 装饰艺术 Art Deco
- 别名： deco、复古豪华
- token：`--bg:#0F2830（墨绿）或 #1A1A2E（墨蓝）; --ink:#F5EDD8（香槟白）; --accent:#D4AF37（金）;`
- 字体：标题衬线或装饰感无衬线，全大写 + 宽字距
- 形状：对称构图；细金线双线框（border + outline 2px 间隔）、阶梯状边角（clip-path 阶梯）
- 标志性元素：金色放射纹（repeating-conic-gradient）、扇形/日冕装饰、菱形分隔符 ◆、细金线框住每块内容
- 动效：金色线条一次性描画（stroke-dashoffset 2s）
- 避坑：不对称布局（Deco 必须严格对称）；超过金+墨底+白三种主色

### 19 科幻 HUD Sci-Fi HUD
- 别名：仪表盘、机甲界面
- token：`--bg:#050B14; --ink:#D8E6F0; --muted:#5A7A99; --accent:#4FC3F7（青蓝）; --accent2:#FFB74D（琥珀警示色）`
- 字体：全部等宽 + 全大写英文小标签（如 `PWR 88%`）
- 形状：切角面板（clip-path 切两角）+ 1px 青色描边 + 角标记号（四角 L 形短线）
- 标志性元素：圆形仪表盘（conic-gradient 刻度环）、数据读出条（细横线 + 数字）、扫描环旋转、瞄准框十字线
- 动效：扫描环旋转（8s linear）、数字滚动刷新（1s step）
- 避坑：做成赛博朋克（HUD 冷静精确、单色青蓝为主，无故障感无粉紫）

## 组 C：布局也换（编号 20-21）

### 20 便当盒布局 Bento Grid
- 别名：bento、格子布局
- token：`--bg:#F3F1EA; --ink:#1C1C1A; --accent:#0E4F45（墨绿）; 面板色板：#DFE9D8（浅豆绿）/ #F5C77E（杏黄）/ #E8DCC8（奶茶）/ #2E2A26（深咖反白）`
- 字体：无衬线，大数字用衬线或等宽
- 形状：统一圆角 16px，格子间 8-12px 等间距，严格对齐无悬空
- 布局规则：一整页 = 6-9 个大小不一的格子（大格 2×2、标准格 1×1、长条格 2×1），每格只放一件事；一页至少一个大格做主视觉
- 标志性元素：每格内一种元素（大数字/小图表/一句话/一个色块图形），格子底色轮流取色板
- 动效：格子逐个入场（stagger 40ms）
- 避坑：格子等大（必须大小混合）；格子内容超过一个重点；间距不一

### 21 新中式 New Chinese Style
- 别名：国风、禅意、水墨
- token：`--bg:#F3EEE3（宣纸米）; --ink:#2B2B28（松烟墨）; --accent:#B03A2E（印泥朱红）; --accent2:#5B7A6F（黛青）;`
- 字体：标题衬线（--font-serif）+ 可竖排（writing-mode: vertical-rl）；正文无衬线小字号
- 形状：直角细线框（1px 墨色）；圆形「月洞窗」容器（border-radius:50% + 山水渐变内容）
- 标志性元素：竖排标题、朱红印章方块（白字或红底白字，2-3 字）、大面积留白、山水渐变圆窗（青绿渐变模拟）、界格线（表格价目用细线界格）
- 动效：几乎无；印章入场可盖印效果（scale 1.2→1 + 透明度）
- 避坑：用饱和红金做「喜庆风」（新中式是素雅文人感）；元素摆满（留白 ≥ 40%）
