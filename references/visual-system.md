# 视觉系统：基调、字体、字号、栅格、间距

## 一、三种基调（只选一种）

### 1. 编辑部 Editorial
- 适用：战略汇报、方案提案、对外评审，需要「有观点、可阅读」。
- 底色 `#F4F1EA` 纸白，主文字 `#16130F` 墨黑，强调色 `#B4402C` 砖红（或 `#1F4E46` 深松绿）。
- 标题用衬线（宋体族），正文用无衬线；标题可左对齐大字号，配 1px 上下细线。
- 视觉签名：大面积留白 + 一条斜向细线 + 页脚页码用衬线小字。
- 避免做成：杂志封面感的满版大图 + 花体字。

### 2. 工程蓝图 Blueprint
- 适用：技术方案、架构设计、数据指标类汇报。
- 底色 `#0E1621` 深墨蓝，面板 `#16212E`，主文字 `#E8EDF2`，次文字 `#8FA0B3`，强调 `#4FD1C5` 青。
- 数字与标签用等宽字体；网格线 `rgba(232,237,242,0.08)`。
- 视觉签名：背景 40px 细网格、坐标刻度、等宽大数字 + 单位小字。
- 避免做成：发光霓虹 + 玻璃拟态卡片堆叠。

### 3. 极简瑞士 Swiss
- 适用：结论先行的高层汇报、时间紧的评审。
- 纯白 `#FFFFFF`，文字 `#111111`，唯一强调色 `#D8232A` 或 `#1A56DB`。
- 全无衬线，超大字重对比（96px 标题对 22px 正文），严格 12 列栅格，左对齐，不用居中堆叠。
- 视觉签名：超大序号、粗细分明的分割线、单色块承载数据。
- 避免做成：彩色卡片九宫格。

## 二、字体栈（只用系统字体，禁外链）

```css
--font-sans: "PingFang SC","Hiragino Sans GB","Source Han Sans SC","Noto Sans CJK SC","Microsoft YaHei",system-ui,sans-serif;
--font-serif: "Songti SC","Noto Serif CJK SC","Source Han Serif SC","SimSun",serif;
--font-mono: "SF Mono","JetBrains Mono",Menlo,Consolas,monospace;
```

数字统一用 `font-variant-numeric: tabular-nums;`，避免跳列。

## 三、字号阶梯（设计基准 1600×900）

| 角色 | 字号 | 行高 | 字重 |
|---|---|---|---|
| 封面主标题 | 96 | 1.1 | 700 |
| 页面标题 | 56 | 1.25 | 700 |
| 小节标题 | 40 | 1.3 | 600 |
| 导语 | 28 | 1.5 | 400 |
| 正文 | 22 | 1.6 | 400 |
| 注释/来源 | 16 | 1.5 | 400 |
| 标签（等宽大写） | 14 | 1.4 | 500，字距 .08em |

字号只允许出现上表 7 个值，不得临时加 18px、32px。

## 四、栅格与间距

- 12 列，列间距 24px，页边距 96px（安全区 1408×708）。
- 间距刻度：8 / 16 / 24 / 40 / 64 / 96 / 128，只取刻度值。
- 圆角：编辑部 0，瑞士 0，蓝图 4px。禁止胶囊按钮与浮动阴影卡片。
- 单页留白不低于 25%，一页只承载一个结论。
- 文本对比度 ≥ 4.5:1；深色底上的次文字不低于 `#8FA0B3`。

## 五、动效

- 仅入场：`opacity 0→1` + `translateY(12px→0)`，240ms，`cubic-bezier(.2,.7,.3,1)`。
- 每页最多 2 个动效元素；图表可做一次性增长。
- 必须 `@media (prefers-reduced-motion: reduce)` 关闭动效。

## 六、反模板化黑名单（出现即判不合格）

1. 紫蓝渐变背景、玻璃拟态、发光边框。
2. 三张等宽圆角卡片并排承载所有内容。
3. emoji 当项目符号或图标。
4. 无意义的英文小标签（如 `OVERVIEW`、`SECTION 01`）铺满页眉。
5. 每个标题下都加一段灰色副标题充当装饰。
6. 图标 + 标题 + 两行字的重复卡片阵列。
7. 满屏投影阴影、`border-radius: 16px` 的万能容器。
