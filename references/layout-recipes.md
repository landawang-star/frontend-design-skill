# 页型配方（六种）

每页先定「这一页要证明什么」，再选页型。同一页型不得连续出现三次以上。

## 1. 封面 Cover
- 结构：基调底色 + 主标题（96px）+ 一行副标题（导语 28px）+ 汇报人/日期（注释 16px，右下或左下）。
- 重心：标题占页面视觉重量 70%，其余为留白。
- 去同质化：主标题可跨两行、第二行缩进 96px 形成错位；不用居中 + 装饰线组合。

## 2. 结论页 Conclusion（建议放第 2 页）
- 结构：一句话结论（40px 或 56px）+ 三条支撑（编号 01/02/03 + 一句话），编号用等宽字体。
- 重心：结论文字本身，不配插图。
- 用途：让评审只看这一页也能过会。

## 3. 数据页 Data
- 结构：一个主指标（96px 等宽数字 + 单位小字）+ 一到两个辅指标 + 一行口径/来源注释；需要时配一条极简趋势线（内联 SVG，无外部库）。
- 重心：数字字号差 ≥ 3 倍。
- 红线：页面上每个数字都必须能在原文找到；没有来源就标「待补充口径」。
- 去同质化：图表不加网格背景、不加图例框，直接标注在线尾。

## 4. 对比页 Comparison
- 结构：左右两栏不同性质（如 现状/目标），中间 1px 分割线；不用两张卡片。
- 重心：差异点用强调色标出，相同点弱化为次文字色。
- 最多 3 组对比，超出拆页。

## 5. 流程/架构页 Process
- 结构：横向 3–6 个节点 + 细线连接，节点只有序号 + 名称 + 一行说明；或纵向时间轴（里程碑）。
- 重心：流向清晰，节点等距。
- 红线：不用箭头图标包，不用彩色圆角块。

## 6. 结尾/行动页 Ask
- 结构：需要的决策或资源（1–3 条）+ 下一步时间点 + 联系人。
- 重心：明确的「要什么」，不写「谢谢观看」大字占一页。

## 版式编排检查
- 连续两页视觉重心必须在不同位置（左/右/上/中）。
- 每 3 页至少一次整页只用文字或只用数字，避免节奏单一。
- 页脚只有页码与一个来源位，不放 logo 墙。
